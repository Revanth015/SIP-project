# Universal Warehouse Digital Twin

A reusable CAD-assisted warehouse digital twin for layout optimization, capacity planning, slot-level analysis, and daily occupancy simulation.

## Current direction

- DXF warehouse geometry ingestion
- CAD-defined warehouse and door selection
- Theoretical vs realistic vs planning capacity
- Configurable operational constraints
- Layout optimization
- Slot master and distance analysis
- Daily warehouse occupancy simulation
- Excel/visual outputs

## Application goal

Create a company-independent decision-support application that can be run locally from Visual Studio and later packaged/deployed as a web application.
